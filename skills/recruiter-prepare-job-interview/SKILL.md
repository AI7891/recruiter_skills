# Interview Preparation

## Operating contract
Use this skill independently or hand its structured result to the next relevant recruitment skill. Reuse existing candidate records; ask only for missing information material to this task. Do not require all sixteen skills to run for a narrow request.
Keep candidate-specific data out of the skill itself. Use an authorized private record with source references and an updated-at timestamp. Treat missing information as unknown, not false. Distinguish facts, inferences and recommendations.
Discover available tools before relying on integrations. Read and use applicable document, calendar, messaging or storage guidance when that operation is needed. Never claim access, scheduling, sending or submission that tools have not confirmed. A skill provides instructions, not credentials, a background worker or platform permissions.

## Inputs
Vacancy, candidate evidence, interview format and available preparation time.

## Workflow
1. Prioritize likely assessed competencies from responsibilities and known interview details.
2. Build behavioral examples with situation, task, action and result; mark missing details instead of inventing success.
3. Run a question at a time when practicing; assess relevance, evidence, clarity and depth before offering a stronger answer.
4. For technical practice, use representative exercises with evaluation criteria and explain mistakes; respect live-assessment rules.
5. Prepare concise career-transition explanations and thoughtful employer questions; finish with a short priority practice plan.

## Deliverable
Question set, evidence-based answer outlines, practice feedback and focused preparation plan.

## Completion check
No claims of knowing actual confidential interview questions; do not coach false experience.
