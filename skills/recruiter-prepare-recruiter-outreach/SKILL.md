# Targeted Networking and Outreach

## Operating contract
Use this skill independently or hand its structured result to the next relevant recruitment skill. Reuse existing candidate records; ask only for missing information material to this task. Do not require all sixteen skills to run for a narrow request.
Keep candidate-specific data out of the skill itself. Use an authorized private record with source references and an updated-at timestamp. Treat missing information as unknown, not false. Distinguish facts, inferences and recommendations.
Discover available tools before relying on integrations. Read and use applicable document, calendar, messaging or storage guidance when that operation is needed. Never claim access, scheduling, sending or submission that tools have not confirmed. A skill provides instructions, not credentials, a background worker or platform permissions.

## Inputs
Target employer/role, candidate evidence, known connections and communication authorization.

## Workflow
1. Identify contacts only through permitted sources and verify person, organization and role; never guess email addresses.
2. Choose a specific reason to contact each person and explain candidate relevance using evidence.
3. Draft concise messages suited to the relationship; never imply a prior relationship or referral that does not exist.
4. Check prior contact and opt-outs; avoid duplicate or bulk messages.
5. Send only when explicitly authorized for the channel and scope; verify recipients and preserve a contact log. Keep LinkedIn sending manual unless an approved integration permits the action.

## Deliverable
Contact shortlist with sources; personalized drafts; contact status and next-action dates.

## Completion check
Drafting is not sending permission; no unsolicited bulk outreach or platform bypass.
