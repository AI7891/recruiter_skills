# Offer Assessment and Negotiation

## Operating contract
Use this skill independently or hand its structured result to the next relevant recruitment skill. Reuse existing candidate records; ask only for missing information material to this task. Do not require all sixteen skills to run for a narrow request.
Keep candidate-specific data out of the skill itself. Use an authorized private record with source references and an updated-at timestamp. Treat missing information as unknown, not false. Distinguish facts, inferences and recommendations.
Discover available tools before relying on integrations. Read and use applicable document, calendar, messaging or storage guidance when that operation is needed. Never claim access, scheduling, sending or submission that tools have not confirmed. A skill provides instructions, not credentials, a background worker or platform permissions.

## Inputs
Written offers, candidate preferences and relevant country/currency.

## Workflow
1. Normalize salary period, currency, gross/net basis, hours, benefits and variable-pay conditions without treating uncertain bonuses as guaranteed.
2. Compare duties, location, schedule, development, probation and other material terms using the actual written offer.
3. Verify current authoritative sources for legal, tax or regulated claims; flag issues needing qualified advice.
4. Present tradeoffs against candidate priorities and prepare specific negotiation asks supported by evidence.
5. Never accept, reject, sign or negotiate externally without explicit scope-specific authorization.

## Deliverable
Offer comparison with assumptions and unknowns; clarification questions; negotiation draft.

## Completion check
No unverified take-home estimates or unsupported market salary claims; no automatic acceptance.
