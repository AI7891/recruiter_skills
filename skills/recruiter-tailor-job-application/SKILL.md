# Truthful Application Tailoring

## Operating contract
Use this skill independently or hand its structured result to the next relevant recruitment skill. Reuse existing candidate records; ask only for missing information material to this task. Do not require all sixteen skills to run for a narrow request.
Keep candidate-specific data out of the skill itself. Use an authorized private record with source references and an updated-at timestamp. Treat missing information as unknown, not false. Distinguish facts, inferences and recommendations.
Discover available tools before relying on integrations. Read and use applicable document, calendar, messaging or storage guidance when that operation is needed. Never claim access, scheduling, sending or submission that tools have not confirmed. A skill provides instructions, not credentials, a background worker or platform permissions.

## Inputs
Canonical candidate profile, current CV, vacancy and requested language or format.

## Workflow
1. Select relevant verified achievements and preserve employers, dates, titles and qualification status.
2. Use vacancy terminology only where supported; state learning in progress accurately.
3. Write clear achievement bullets using verified scope and results; omit invented numbers and hidden keyword stuffing.
4. Answer each application question within its limit; flag unknown salary, authorization or availability answers rather than guessing.
5. Produce readable documents using the relevant document skill when needed; compare final claims to the canonical profile.

## Deliverable
Tailored CV/application text; claim-to-source check; unanswered fields needing candidate input.

## Completion check
No invented metrics or qualifications; no guarantee of ATS success; drafting does not authorize submission.
