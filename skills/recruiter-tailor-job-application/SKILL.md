# Truthful Application Tailoring

## Operating contract
Use this skill independently or hand its structured result to the next relevant recruitment skill. Reuse existing candidate records; ask only for missing information material to this task. Do not require every skill in this set to run for a narrow request.
Keep candidate-specific data out of the skill itself. Use an authorized private record with source references and an updated-at timestamp. Treat missing information as unknown, not false. Distinguish facts, inferences and recommendations.
Discover available tools before relying on integrations. Read and use applicable document, calendar, messaging or storage guidance when that operation is needed. Never claim access, scheduling, sending or submission that tools have not confirmed. A skill provides instructions, not credentials, a background worker or platform permissions. If a tool, site or permission refuses an action, report it as blocked, say what the owner can do next, and do not route around the refusal.

## Inputs
Canonical candidate profile, current CV, vacancy and requested language or format.

## Workflow
1. Select relevant verified achievements and preserve employers, dates, titles and qualification status.
2. Use vacancy terminology only where supported; state learning in progress accurately.
3. Write clear achievement bullets using verified scope and results; omit invented numbers and hidden keyword stuffing.
4. Answer each application question within its limit; flag unknown salary, authorization or availability answers rather than guessing.
5. Write a cover letter for each vacancy the user names or approves, and for every vacancy in an approved shortlist unless the user declines. Keep it to one page, in the vacancy's language unless told otherwise. Open with the specific role and employer. Make two or three points, each tied to a verified candidate example and, where available, a documented employer need from an employer brief. State gaps and learning in progress honestly without apology or invention. Avoid generic flattery and template filler.
6. For a shortlist, handle each vacancy independently and return one clearly labeled draft per vacancy. Never reuse a letter body for another employer without rechecking every employer-specific claim. Mark a vacancy blocked when its requirements are unknown; do not stop the other drafts.
7. Produce readable documents using the relevant document skill when needed; compare final claims to the canonical profile.
8. For a CV variant for another role family, keep the candidate's existing design and change only the text. Take every new line from the candidate's own documents, list what was dropped, added or reworded, and add no skill, tool or credential the sources do not show.
9. Before delivery, proofread names, dates, spelling and numbers against the canonical profile, and confirm the document has a real text layer by extracting its text. An image-only file cannot be read by applicant tracking systems, so say so and offer a text-based version.

## Deliverable
Tailored CV/application text; one cover letter draft per approved vacancy; claim-to-source check; unanswered fields needing candidate input.

## Completion check
No invented metrics, qualifications or employer facts; no guarantee of ATS success; no unreadable image-only CV delivered as final; drafting does not authorize submission.
